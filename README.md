# Nostra – E-commerce Website

Nostra is a responsive fashion e-commerce website built using HTML, CSS, and JavaScript. It allows users to explore collections, search for products, and filter products by category.

## Features

* **Home Page:** Displays featured products and promotional sections.
* **Collections Page:** Displays products with search and category filtering.
* **Contact Us Page:** Includes contact information and a contact form.
* **Search Functionality:** Search for products by name.
* **Filter Functionality:** Filter products by category using JavaScript.
* **Responsive Design:** Works on desktop, tablet, and mobile devices.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Navigate between the Home, Collections, and Contact Us pages.
5. Test the search and category filter features on the Collections page.
